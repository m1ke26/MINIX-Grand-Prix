◆ vg_init_double_buffer()

int vg_init_double_buffer ( uint16_t width,
uint16_t height,
uint8_t bytes_per_pixel )

Initializes the back buffer for double buffering.

Parameters
widthThe width of the back buffer (should match screen width).
heightThe height of the back buffer (should match screen height).
bytes_per_pixelThe number of bytes per pixel (e.g. 3 for 24-bit color).
Note
The back buffer is used for off-screen drawing to prevent flickering. After drawing to the back buffer, call vg_buf_swap() to copy it to the screen.
Returns
0 on success, -1 on failure.
